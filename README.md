# 📱 Atividade 5 - Exercícios React Native

Projeto desenvolvido em **React Native** utilizando **Expo** e **TypeScript**, contendo 5 exercícios práticos de desenvolvimento mobile.

## 🚀 Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
- JavaScript/TypeScript
- VS Code

## 📚 Exercícios

### 1️⃣ Lista de Contatos

Criação de uma lista de contatos utilizando `FlatList`.

**Requisitos desenvolvidos:**
- Array com 5 contatos
- ID, nome e telefone
- Exibição do nome e telefone
- Cards para cada contato

---

### 2️⃣ Formulário de Cadastro

Formulário contendo três campos para cadastro de usuário.

**Campos:**
- Nome
- Email
- Telefone

**Funcionalidades:**
- Botão "Cadastrar"
- Validação dos campos
- Exibição dos dados através de `Alert`

---

### 3️⃣ Lista de Tarefas

Lista de tarefas utilizando `FlatList` e checkbox visual.

**Funcionalidades:**
- 5 tarefas
- Checkbox visual
- ✓ para tarefa concluída
- ○ para tarefa pendente
- Texto riscado quando concluída
- Possibilidade de alterar o status da tarefa

---

### 4️⃣ Calculadora de IMC

Calculadora do Índice de Massa Corporal.

**Entradas:**
- Peso em kg
- Altura em metros

**Funcionalidades:**
- Cálculo do IMC
- Exibição do resultado
- Classificação do IMC

IMC = peso / (altura × altura)
